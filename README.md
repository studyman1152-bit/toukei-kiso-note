HTML 1ファイルで完結していて、サーバも外部CDNも使いません。

**公開ページ** → https://studyman1152-bit.github.io/toukei-kiso-note/

## 特徴

- **用語ポップアップ** … 本文中の点線が引かれた用語をタップすると、その場で意味が出ます。上に戻る必要がありません（約85語）
- **用語検索** … 上部バーの「用語をひく」から漢字でもひらがなでも引けます
- **習得度チェック** … チェック状態は localStorage に保存され、ブラウザを閉じても残ります
- **A4持込メモの字数カウンタ** … 手書きでA4片面に収まるかを字数で判定
- **レスポンシブ** … 320px幅のスマホから確認済み。印刷用CSSも別途あり

## 使い方

`index.html` をブラウザで開くだけです。ビルドも依存パッケージもありません。

## 注意

- 模擬試験・計算ドリルは講義の強調点から出題形式を再現した**学習用の練習問題**であり、実際の出題を示すものではありません。
- A4持込メモは**手書きのみ可**。このページの印刷物は試験に持ち込めません。
